#  Лабораторная работа №1
## Тема лабораторной работы: *Динамические структуры данных. Обработка деревьев*
Цель работы: Составить программу на языке Си для построения и обработки дерева общего вида или упорядоченного
двоичного дерева, содержащего узлы типа iпt. Основные функции работы с деревьями реализовать в виде отдельных
функций.

## *Идея, метод, алгоритм решения задачи:*
Метод решения основан на рекурсивных алгоритмах обхода и модификации структуры, что обеспечивает удобную работу с узлами. Ключевые алгоритмы включают: вставку нового элемента с сохранением свойства бинарного дерева, удаление узла с обработкой трех случаев, вычисление степени дерева как максимума количества потомков среди всех вершин и корректное освобождение памяти обратным обходом.

## *Сценарий выполнения работы:*
Разработка началась с проектирования структуры данных и реализации рекурсивных алгоритмов управления деревом, затем были созданы модуль автоматического тестирования и консольный интерфейс, а завершил работу процесс настройки системы сборки и финальной отладки.
